#  Change

class in mod.common.minecraftEnum

- 描述

刷怪设置参数枚举，用于[SpawnCustomModule](https://mc.163.com/dev/mcmanual/mc-dev/mcdocs/1-ModAPI-beta/接口/世界/生物生成.html#spawncustommodule)

```python
class Change:
	Add = 0     # 新增自定义刷怪区域
	Remove = 1  # 移除自定义刷怪区域

```
