#  HorseType

class in mod.common.minecraftEnum

- 描述

描述马的变体颜色

```python
class HorseType:
	White = 0  		# 白色
	Creamy = 1  	# 淡栗色
	Chestnut = 2  	# 深枣红色
	Brown = 3  		# 褐色
	Black = 4 		# 黑色
	Gray = 5  		# 灰色
	Darkbrown = 6  	# 深褐色

```
