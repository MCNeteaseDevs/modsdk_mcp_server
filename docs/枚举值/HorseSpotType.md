#  HorseSpotType

class in mod.common.minecraftEnum

- 描述

描述马的斑点种类

```python
class HorseSpotType:
	NoneSpot = 0  		# 无斑点
	WhiteStockings = 1  # 白袜
	WhiteField = 2  	# 雪片白斑
	WhiteDots = 3  		# 白色斑点
	BlackDots = 4 	 	# 黑色斑点

```
