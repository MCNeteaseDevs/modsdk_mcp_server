#  自定义书本

##  GetBookManager

客户端

method in mod.client.extraClientApi

- 描述

获取书本管理对象

- 参数

无

- 返回值

| 数据类型 | 说明 |
| --- | --- |
| BookManager | 所有书本的管理对象 |

- 示例

```python
import mod.client.extraClientApi as clientApi
bookManager = clientApi.GetBookManager()

```
