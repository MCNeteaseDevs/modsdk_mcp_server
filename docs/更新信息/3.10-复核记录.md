# ModSDK 3.10 稳定版推送前复核

复核日期：2026-11-03。范围：官方来源、当前知识快照、版本指导、同步器及 PR 相对于上游的改动。

## 已发现并处理

- 官方 3.10 已于 2026-10-28 上线稳定版，原 `1-ModAPI-beta` 链接返回官网错误页。版本档、规则、说明、来源与全部当前文档改为稳定版；稳定版状态以本次抓取的官方正文和频道确认。
- 稳定版相对先前 Beta 快照有 6 个接口条目和 3 个事件说明修订，没有接口或事件增删：
  - `GetActorFlags` 修正为 bit1=`eDISABLE_GRAVITY`、bit2=`eSEND_SLEEP_NOTIFIES`、bit3=`eDISABLE_SIMULATION`。
  - `AddBoxGeometry`、`AddBoxTrigger`、`AddCapsuleGeometry`、`AddSphereGeometry` 明确未移除 Shape 共用 8192 总数上限。
  - `SetCommand` 增加极限模式下无法执行需要作弊的指令的说明。
  - `LiquidClippedClientEvent` 与 `LiquidClippedServerEvent` 补回 `netease:liquid_clipped` 必需组件条件。
  - `RightClickReleaseClientEvent` 补回新触控交互键的说明。
- 同步器验证官方频道实际版本，避免旧更新页仍存在时，将已滚动更新的接口索引误冻为旧版本。3.9 冻结基线原字节保持不变。
- 全部当前页面引用已核对，官网物理正文中 5 处多写 `接口/` 的枚举链接已归并到实际抓取的正确枚举页；原始地址及正确地址保存在 `official-docs.json` 的 `current.reference_aliases`，不将坏链接当作缺失能力。
- 移除 `ast.Str` 旧别名依赖，保留 `ast.Constant` 路径以兼容当前宿主 Python。
- 以最新上游 `origin/main` 为基线，保留管理员已合并的通用路径检查、可移植配置与 SSE 入口修复；PR 不包含本机路径配置或离线测试改动。
