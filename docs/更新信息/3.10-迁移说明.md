- 教程为非版本化官方页面，只能证明当前公开配置，不能直接归因于 3.9→3.10。
- 文档、构建和文件核对不构成游戏功能验收。

| 接口 | 1612 | 1702 | 90 | 0 | 23 |
| 事件 | 298 | 304 | 6 | 0 | 0 |
| 枚举常量 | 1232 | 1240 | 8 | 0 | 2 |
| 参考文档页 | 191 | 195 | 6 | 2 | 20 |

接口变化中 12 项只有分类迁移，11 项包含参数、描述、备注或示例变化。参考文档页不再出现包含旧物理分类页迁移和版本更新页频道变化，不是接口删除。
计数保留客户端、服务端、双端与 Apollo 的官方条目；相同引擎方法的重复分类引用只计一次。

## 迁移时需要处理的行为与其他内容

### 3.10 对应 BE 1.21.130，已提供官方稳定版文档

- 按 2026-10-28 上线的官方稳定版文档核对接口与来源
- 区分更新日志明确新增与索引首次出现；游戏行为须实机验收

### 3.10 物理接口仍属实验性能力

- 按当前 PhysxComponentServer/Client 正文查询签名、端侧与生命周期
- 保留可替换的业务边界，并在真实世界中验收

### 碰撞体支持运行时增加，并增加 density 参数

- 服务端四个接口可在创建自定义刚体后的脚本时机调用，density 默认 10.0 且必须大于 0
- 碰撞体变化会重算质量、质心和惯性张量；触发器不参与刚体质量计算
- 客户端 AddBoxGeometry 仅修改本地副本，不自动同步服务端
- 当前世界中未移除的盒形、胶囊形、球形 Shape 与盒形触发器共同计入 8192 总数上限

### 施力单位、运动学刚体与速度上限须遵守 3.10 约束

- AddForce 按 PxForceMode 区分 N、N·s、m/s 和 m/s²
- AddTorque 对运动学刚体返回 False；速度上限参数按正文检查有限正数

### 关节阈值、类型与断裂回调按 3.10 正文处理

- SetJointBreakForce 中 -1 表示不可断裂，有限阈值须非负
- GetJointType 和 PhysXJointBreakServerEvent 支持 4=Prismatic
- 断裂事件包含 breakForce、breakTorque；关节须 DestroyJoint 显式释放

### 物理模拟前后事件大小写与同步时序必须准确

- 事件名保留 PhysX 大写 X，参数为 dimensionId、deltaTime
- 同步高频回调只执行轻量状态读写；模拟后当帧结果从 PhysX 组件读取
- 按端侧与参与物理模拟的维度理解触发范围

### 屏幕与世界坐标转换使用真实渲染视口像素

- 屏幕坐标以左上角为原点，使用 GetScreenViewInfo 的真实渲染视口尺寸
- 射线结果为 origin、direction；投影结果为 screenX、screenY、depth、isInScreen
- 矩阵、宽高比和近远裁剪面接口只提供基础能力，按正文自行处理计算

### 房间元数据查询为异步请求，并受联机大厅边界限制

- GetRoomMeta(callback, roomId) 的直接返回值仅表示是否发起请求，结果由回调返回 dict 或 None
- SetRoomMeta 的 key 为 str，value 必须可 JSON 序列化
- 处理非联机大厅、房间不存在和请求失败

### 房主 uid 与实体 id 必须区分并允许离线空实体

- 按 GetHostPlayerUid、TransferRoomHost/ByUid 和 KickPlayer/ByUid 的正文区分 uid 与 entityId
- 处理 RoomHostChangedServerEvent 的 newUid、newEntityId、oldUid、oldEntityId
- 首次设置房主 oldUid 为 0，离线实体 id 可为 None；踢人接口排除房主

### 自定义方块与物品标签独立注册并支持跨模组合并

- 行为包 netease_tags 中每个 JSON 注册一个 type=item/block 的 identifier
- 相同标签跨模组追加并去重，支持 #identifier 引用；原版标签也能查询
- 使用 LookupBlocksByBlockTag 或 LookupItemsByItemTag 核对对应返回结构

### 纹理图集查询区分 terrain 方块图集与物品图标

- GetTextureAtlasUV 仅用于 atlas.terrain；物品图标使用 GetIconInfo
- 处理图集接口获取失败时返回 None，返回 UV 为归一化坐标
- 调色板合并新增模型支持以 3.10 三个 CombineBlock 接口备注为准

### 云层贴图 clouds.png 不得使用 1×1 尺寸

- 使用非 1×1 尺寸云层贴图，并在目标渲染引擎中实机观察

### 自由模型可以绑定维度，-1 表示全维度可见

- 按 CreateFreeModel 当前参数核对 dimensionId
- 使用 SetFreeModelDimensionId(modelId, dimensionId) 设置可见维度

### 附魔枚举新增 Lunge，结尾枚举数值顺延

- 通过当前 EnchantType 枚举名访问附魔
- 3.10 新增 Lunge=41，NumEnchantments=42、InvalidEnchantment=43；迁移持久化数值时核对映射

## 本工具升级方式

- 默认 ModSDK、BE 上限与发布状态统一读取版本注册表；历史版本保留规则入口，API 检索明确使用当前完整快照。
- 全量重建接口、事件和官方导航；按类路径、名称、端侧去重，保留不同类的同名方法。
- 已消失的旧官方分类正文从当前全文索引移除，旧条目清单单独保留，不混入当前 API。
- 官方事件生成器使用查证后的标准名称，保留 PhysX 大写 X，并明确排除普通双端生成器不支持的独立服务器事件。
- 新增 get_version_changes、modsdk-guidance://changes 和当前版本迁移规则；迁移报告由同一份差异自动生成。
- 同步前完成全部抓取和数据核对，再事务性创建、替换、移除文件；写入失败会回滚。运行时不联网。

## 制作检查与实机边界

不编写、恢复或运行离线单元测试。JSON、来源、条目、哈希、重复身份、编码和 Python 编译核对只属于制作检查，不构成游戏功能测试通过。
本次没有启动游戏，没有对 3.10 的接口行为作实机验收；官方文档同步不等同于运行时源码复核。
